# Legacy Phase 1 Scaffolding Archive

This directory contains historical prototyping notes, exploratory drafts, and early scaffolding from Phase 1 of the Five-Head Story-Generation System project.

## Archived Folders

- `scratch/`: Early exploratory specifications and design notes for visual story generator logic.
- `unplugged/`: Initial conceptual notes and classroom role-play worksheets.
- `streamlit_app/`: Early prototype interface file (`app.py`).

## Production Implementations

These historical artifacts have been superseded by production components:

- **Classroom Curriculum & Visual Implementation:** Located in `phase_7/` (`phase_7/scratch/` and `phase_7/classroom/`).
- **Streamlit Application:** Located in `src/five_head_nlp/ui/` and launched via the `five-head-studio` console command.
- **Story Generation Core:** Located in `src/five_head_nlp/`.
